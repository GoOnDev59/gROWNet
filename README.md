# 🌱 GrowNet — Internship & Career Readiness Platform

GrowNet is a web-based platform designed to help students discover relevant internship opportunities, identify skill gaps, assess their placement readiness, and receive AI-powered career guidance. It also enables students to save and compare internships, track application deadlines, and explore opportunities through skill-based matching.

## ✨ Key Features
- Explainable skill-based internship matching
- Placement readiness checklist
- AI Career Assistant
- Recruiter and internship verification
- Internship deadline tracking
- Save, search, filter, and compare internships

## 🛠️ Tech Stack
- **Frontend:** React 19, Vite, Bootstrap 5
- **Backend:** Java 21, Spring Boot, Maven
- **Database:** MySQL 8
- **Security:** Spring Security, JWT
- **AI:** LLM API
- **Tools:** Git, GitHub, Postman
